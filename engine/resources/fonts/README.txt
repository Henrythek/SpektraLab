The film edge's text outside macOS. Off Apple the engine has no Helvetica
Neue (it cannot be redistributed); TeX Gyre Heros is a Helvetica clone with
the same metrics. HelveticaNeue -> regular; HelveticaNeue-Bold and
HelveticaNeue-Medium -> bold (Heros has no medium weight).
overscan.cpp / edge_raster.cpp read these; the macOS build uses CoreText.
